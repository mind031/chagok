# 차곡차곡

내가 스스로 하는 하루 미션 스티커판. 아이패드와 갤럭시 홈 화면에 설치해서 쓰는 웹앱이에요.

## 들어 있는 파일

| 파일 | 하는 일 |
|---|---|
| `index.html`, `app.js` | 앱 화면과 동작 |
| `board.webp` | 스티커판 배경 그림 |
| `manifest.webmanifest`, `sw.js`, 아이콘들 | 홈 화면 설치와 인터넷 없을 때 열기 |
| `firebase-config.js` | 온라인 저장소 연결 정보 (2단계에서 채워요) |
| `firestore.rules` | 우리 가족만 읽고 쓰게 막는 보안 규칙 |

파이어베이스를 연결하기 전에도 앱은 작동해요. 그때는 기록이 그 기기에만 저장돼요.

---

## 1단계. 깃허브에 올리기

1. 깃허브에서 오른쪽 위 **+ → New repository**.
2. 이름은 `chagok` 처럼 정하고 **Public**으로 만들어요.
3. 저장소 화면에서 **Add file → Upload files**를 눌러 이 폴더의 파일을 **전부** 끌어다 놓고 **Commit changes**.
4. **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 하고 **Save**.
5. 1~2분 뒤 `https://내아이디.github.io/chagok/` 주소가 생겨요. 열어서 판이 보이면 성공이에요.

## 2단계. 파이어베이스 연결하기 (두 기기에서 같은 판 보기)

무료 요금제(Spark)로 충분해요.

1. https://console.firebase.google.com 에서 **프로젝트 추가** → 이름 `chagok` → 구글 애널리틱스는 꺼도 돼요.
2. 프로젝트 첫 화면에서 **웹 앱 추가(</> 아이콘)** → 별명 `chagok` → 등록하면 `firebaseConfig = { apiKey: ..., ... }` 가 나와요.
3. 그 값들을 `firebase-config.js`의 `"여기에 ..."` 자리에 하나씩 옮겨 적어요.
4. 왼쪽 메뉴 **Authentication → 시작하기 → 이메일/비밀번호**를 켜요.
5. **Authentication → Users → 사용자 추가**로 가족 계정 하나를 만들어요. (예: 엄마 이메일 + 새 비밀번호) 이 계정 하나로 두 기기에서 로그인해요.
6. 왼쪽 메뉴 **Firestore Database → 데이터베이스 만들기** → 위치는 **asia-northeast3 (서울)** → **프로덕션 모드**.
7. Firestore의 **규칙** 탭에 `firestore.rules` 내용을 그대로 붙여 넣고 **게시**.
8. 고친 `firebase-config.js`를 깃허브에 다시 올려요. (저장소에서 파일을 열고 연필 아이콘으로 고치거나, Upload files로 덮어쓰기)

### 보안에 대해

- `firebase-config.js`의 값은 원래 공개되는 주소 정보라 Public 저장소에 올려도 괜찮아요.
- 실제로 기록을 지키는 건 **로그인**과 **보안 규칙**이에요. 규칙 때문에 가족 계정으로 로그인한 기기만 우리 판을 읽고 쓸 수 있어요.
- 앱 안의 **엄마·아빠 비밀번호 4자리**는 아이가 스스로 승인하지 못하게 막는 잠금이에요. 가족 계정 비밀번호와 다르게 정해 주세요.
- 가족 계정 비밀번호는 저장소나 파일 어디에도 적지 마세요.

## 3단계. 홈 화면에 설치하기

**아이패드 (사파리)**
1. 사파리로 `https://내아이디.github.io/chagok/` 열기
2. 공유 버튼(네모에 위 화살표) → **홈 화면에 추가** → 추가
3. 홈 화면의 곰돌이 아이콘으로 열고, 가족 계정으로 한 번 로그인

**갤럭시 (크롬 또는 삼성 인터넷)**
1. 같은 주소 열기
2. 크롬: 오른쪽 위 ⋮ → **홈 화면에 추가** 또는 **앱 설치**
   삼성 인터넷: 아래 ≡ → **현재 페이지 추가 → 홈 화면**
3. 곰돌이 아이콘으로 열고 같은 가족 계정으로 로그인

## 쓰는 법

- 아이가 칸을 누르고 스티커를 고르면 흐리게 **확인 중**으로 붙어요.
- **🔒 엄마·아빠 확인**을 눌러 비밀번호 4자리를 넣으면 부모 모드. 처음 누를 때 비밀번호를 정해요.
- 부모 모드에서는 흐린 스티커를 승인하거나 떼고, 빈칸에 바로 붙일 수도 있어요. 5분 동안 아무것도 안 하면 자동으로 잠겨요.
- 승인된 스티커 수가 자동으로 세지고, 30·40·50·60·65개 단계에 금색 체크가 붙어요.
- **그동안 받은 용돈**은 지금 보는 주 바로 전 주까지의 용돈을 다 더한 금액이에요.
- 날짜를 눌러 캘린더로 다른 주를 보거나, ‹ › 로 지난주·다음 주로 넘어가요.

## 고친 뒤 다시 올릴 때

파일을 고쳐 올렸는데 기기에 예전 화면이 보이면, `sw.js` 맨 위 `chagok-v1`을 `chagok-v2`처럼 숫자를 올려서 같이 올려 주세요. 앱을 한 번 껐다 켜면 새 화면이 나와요.
